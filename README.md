# DigiMunshi Landing Page 🎙️🇵🇰

> Official promotional and download landing page for **DigiMunshi (دیجیٹل منشی)** — Pakistan's first AI-powered voice ledger application designed for local kiryana, general store, and wholesale merchants.

---

## 🌟 Highlights

- **Ultra-Fast & Responsive**: Built with **Vite** and **Tailwind CSS v4** for near-instant load times on mobile 3G/4G connections.
- **Full Bilingual Experience**: Instant client-side toggle between **Urdu (نستعلیق / RTL)** and **English (LTR)**.
- **Modern Vector Aesthetics**: Powered by **Lucide Icons** and bespoke mobile SVG brand assets with an electric `#F05700` brand palette.
- **Interactive App Showcase**: Embedded demo video player, interactive mobile app mockup, and FAQ accordion.
- **Direct APK Distribution**: One-click download trigger for the Android application bundle (`DigiMunshi.apk`).

---

## 🚀 Tech Stack

- **Framework**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconography**: [Lucide Icons](https://lucide.dev/) + Custom Vector SVGs
- **Typography**: Google Fonts (*Inter* and *Noto Nastaliq Urdu*)

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
